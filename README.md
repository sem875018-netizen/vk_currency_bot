# VK Currency Bot

Учебный бот для сообщества ВКонтакте, конвертирующий валюты по актуальному курсу.

## 🚀 Возможности
- Конвертация между популярными валютами: **евро**, **доллар**, **рубль**.
- Актуальные курсы через открытый API `exchangerate-api.com`.
- Детальная обработка ошибок пользователя с выводом понятных сообщений.

## 📋 Доступные команды
- `/start` или `/help` — инструкции по работе с ботом.
- `/values` — список поддерживаемых валют.
- `<валюта 1> <валюта 2> <количество>` — конвертация (например: `евро доллар 100`).
